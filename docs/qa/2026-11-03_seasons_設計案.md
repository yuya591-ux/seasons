## 2-2. 試作の途中で受けた望み（2026-11-03 のチャット・原文）

## 3. 別案の照らし（もっと良い案は無いか）

| 案 | 本物らしさ（計算だけで出せるか） | 北寺尾との違い | 飛ぶ・降りる | 結論 |

## 4. 決めたこと（Claude Code が推奨で決めた・変えたい時だけ裕也さんが言う）

- 新しい町は角部屋の6情景だけに使う。北寺尾・谷戸の情景は変えない
- 飛ぶ・降りる（L1）: 今の仕組みに町の種類「川の町」を足して載せる。北寺尾の町へは行けなくなる（角部屋から飛ぶと川の町）
- iPhone（L4）: 同じ町を軽い段で出す
- 作る順: 便17 窓からの眺め（町・川・土手・鉄橋・空・季節と時刻・R1 の木・R2 の町並み）→ 便18 降りて歩く所の作り込み（L2・R2 の細部）と当たり判定・着地 → 便19 音と時々の出来事 → 揃ったら本番の問い（L14）→ 後の便で川・湖・海の中（R3）
- 水彩の層は川の町に掛けない（L8）。実在の場所に似せない（L9）。画像を使わない（L10）
