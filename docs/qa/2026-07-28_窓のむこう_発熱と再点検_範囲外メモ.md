# 範囲外の発見（2026-07-28 検収）

## 1. 音の設定値に非有限値（NaN/Infinity）が混入する

- **発見箇所**: コンソール `Failed to execute 'setTargetAtTime' on 'AudioParam': The provided float value is non-finite.`（`scripts/qa-fact3.mjs` 実行中に199件）
- **症状**: Web Audio のパラメータ設定が例外で弾かれる。音量・フィルタの遷移が適用されない瞬間がある
- **再現方法**: `?dev=1` で窓辺 → 窓をあける → 飛行 → 雲海 → 着地、と続けて操作すると連続で出る。発生源のファイル・行は未特定
- **深刻度**: 中。音が消える・途切れる不具合の温床。ただし今のところ耳で分かる破綻は未確認

## 2. 雲海の高度帯（y≒92）で画面が白い霞にほぼ覆われる

- **発見箇所**: `docs/qa/2026-07-28/10_雲海_近接_b.png`（`__town3dFlyPose(0, 92, -60, 0, -0.25)`）
- **症状**: 画面の約95%が淡いベージュ一色。雲上の島・東屋・かもめ・下界の山がすべて幽霊のようにしか見えない
- **原因の切り分け**: 雲の白い塊は出ていない＝#289の雲の近接フェードは効いている。**霧（大気の霞）がこの高度帯で強すぎるのが原因**
- **再現方法**: 飛行して高度90前後、雲海デッキのすぐ下で水平に近い視線
- **深刻度**: 中。雲海は本作の見せ場のひとつで、そこが「白い画面」になる時間帯がある
