## 全時代に共通して欠けているもの

現状の73体は **働き盛りの成人男女しか居ない**。年齢の幅がまったく無い。

| 欠けている層 | なぜ要るか | シルエットの作り分け |
|---|---|---|
| **子供** | 街に子供が居ないと「暮らし」でなく「職場」に見える。賑わいの体感を最も強く左右する | 背丈を大人の 0.6〜0.7 倍にするだけでは足りない。**頭を相対的に大きく（3.5〜4頭身）・肩を狭く・手足を短く**。走る・しゃがむ姿勢を1つ持たせる |
| **老人** | 時間の層。同じ街に長く暮らしてきた気配が出る | **背を低く・背中を丸め・膝をわずかに曲げる**。杖の有無で1段変わる。歩調を遅く |

| **座っている人・しゃがんでいる人** | 全員が立って歩いていると行進に見える。腰掛けが1人居るだけで「そこに居る」感が出る | 腰・膝を折った1ポーズ。縁台・石段・畦に付ける |

## 造形の作り分けを、部品の追加数で見積もる

「時代ごとに全部作り直す」ではなく、**既にある部品の組み替えでどこまで行けるか**を先に確認した。

| 追加する部品 | 使える先 | 新規メッシュ |
|---|---|---|
| **股引・脚絆（丈の短い下衣）** | 江戸の職人・戦国の農夫・雲海の棚田 | 既存 `buildLegs()` を呼ぶだけ。**新規ゼロ** |
| **たすき掛け（袖をたくし上げる）** | 戦国の農婦・江戸の女房 | 既存 `buildArms(mat, false)` に切り替えるだけ。**新規ゼロ**（手も同時に付く） |
| **胸高の帯（女性の着物）** | 江戸・戦国・雲海の女性全員 | 既存の帯シリンダーの y を上げるだけ。**新規ゼロ** |
| **結い上げ髪** | 江戸・戦国の女性 | 球1〜2個。**+2** |
| **前掛け** | 職人・茶屋・買い物 | 板1枚。**+1** |
| **背負子・ランドセル・荷物** | 戦国の人足・現代の小学生 | 箱1個。**+1** |
| **天秤棒／日傘／鍬／盆** | 江戸の棒手振り・大正の女性・雲海 | 細い円柱1〜2本。**+1〜2** |
| **子供の比率** | 全時代 | 頭・胴・手足のスケール値のみ。**新規ゼロ** |
| **老人の背中の丸み** | 全時代 | 胴のロフトのリング座標のみ。**新規ゼロ** |

**要点**: いちばん効く5つ（脚の出る下衣・たすき掛け・胸高の帯・子供の比率・老人の背中）は、**すべて新規メッシュ0個**で作れる。
つまり **「マネキン脱却」と「時代の配役をそろえる」の主要部分は、描画コストをほとんど増やさずに到達できる**。
装飾（結い上げ髪・前掛け・荷物・小物）を足すぶんだけが増加分で、1体あたり +1〜4メッシュ。実際にどこまで許されるかは `#9`〜`#11` の実測で決める。
