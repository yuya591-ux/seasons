# 実機確認の手順（1回で終わらせる・2026-07-28）

目的: 机上では測れない「画素の塗り仕事＝発熱」を、同じ条件のA/Bで1回だけ確かめる。

## 前提をそろえる（ここがズレると比較にならない）

- 画面の明るさ **50%固定**（自動調整オフ）
- 低電力モード **オフ**
- 他アプリを全部終了、機内モードは**オフのまま**
- Safariで開く（アプリ内ブラウザは不可）
- 開始前に本体を室温で5分放置（前の熱を抜く）

## A: 新しい版（既定）

https://yuya591-ux.github.io/seasons/

1. 窓辺のまま**5分**眺める（触らない）
2. そのあと窓をあけて飛び立ち、**5分**飛ぶ
3. 記録: 背面の熱さ（3段階: ぬるい／温かい／熱い）・バッテリー残量の減り・カクつきを感じた場面・画質が荒くなったと感じた場面

## B: 前の版（比べる相手）

https://yuya591-ux.github.io/seasons/?fullcss=1&nomerge=1

`?fullcss=1` = 画面全体に重ねる層を従来の5層に戻す／`?nomerge=1` = 建物の統合を止める。
**Aと同じ手順・同じ時間**で繰り返す。開始前にまた5分冷ます。

## 見てほしいこと（AとBで違いが出るか）

| 項目 | A（新） | B（旧） |
|---|---|---|
| 5分後の背面の熱さ | | |
| 10分でのバッテリーの減り | | |
| 窓辺の絵の鮮明さ（差を感じるか） | | |
| 飛行中の絵の粗さ（差を感じるか） | | |
| カクつき | | |

**飛行中だけ解像度を下げる変更が入っている。** 窓辺は従来どおりの鮮明さ。もし飛行中の粗さが気になるなら、そこは戻せる（1行）。
