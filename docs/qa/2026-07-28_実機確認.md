# 実機確認の手順（1回で終わらせる）

- 作成: 2026-07-28 ／ 最終更新: 2026-07-30（統合の第2弾・修正4件を反映）

目的: 机上では測れない「画素の塗り仕事＝発熱」と「体感の滑らかさ」を、同じ条件のA/Bで1回だけ確かめる。

**なぜ実機でしかできないか**: 開発機での fps は、同じコール数でも回によって 6.7〜9.4 と振れる（背景の混み具合で変わる）。机上で信用できるのは描画コール・解像度・カクつき率・エラー数まで。**熱と体感は実機だけが答えを持っている**。

## 前提をそろえる（ここがズレると比較にならない）

- 画面の明るさ **50%固定**（自動調整オフ）
- 低電力モード **オフ**
- 他アプリを全部終了、機内モードは**オフのまま**
- Safariで開く（アプリ内ブラウザは不可）
- 開始前に本体を室温で5分放置（前の熱を抜く）

## A: 新しい版（既定）

https://yuya591-ux.github.io/seasons/

1. 窓辺のまま**5分**眺める（触らない）
2. 窓をあけて飛び立ち、**4分**飛ぶ
3. 着地して**3分**歩く
4. 記録: 背面の熱さ（3段階: ぬるい／温かい／熱い）・バッテリー残量の減り・カクつきを感じた場面・画質が荒くなったと感じた場面

## B: 前の版（比べる相手）

https://yuya591-ux.github.io/seasons/?fullcss=1&nomerge=1

- `?fullcss=1` ＝ 画面に重ねる層を従来の5層へ戻す
- `?nomerge=1` ＝ **統合をすべて止める**（建物の区画・電線・電柱・太鼓橋）

**Aと同じ手順・同じ時間**で繰り返す。開始前にまた5分冷ます。

## 今回あわせて直したもの（目で確かめたい4件）

1. **窓辺のほこり** — 光の中で舞う塵が「四角」に見えていた。丸くなっているか
2. **着地したときの足元** — 走っている車の上に降りて灰色一色になることがあった。地面に降りるか
3. **雲へ入るとき** — 目の前が真っ白になることがあった。雲がふわりと透けて通り抜けられるか
4. **音** — 駅・祭りの音の定位で毎フレーム例外が出ていた（音が途切れる原因）。音が途切れないか
